Desafio Técnico – Desenvolvedor(a) Full Stack (.NET + Angular) 

🎯 Objetivo: - Criar uma aplicação full stack simples para cadastro de produtos, com funcionalidades de listagem, criação, edição e exclusão. 

🧱 Estrutura do Projeto: - backend/: API RESTful em .NET com Entity Framework e banco em memória. - frontend/: Interface Angular com listagem, formulário e integração com API. 

🛠 Requisitos: - Backend: .NET 6+, Entity Framework, boas práticas (SOLID, Clean Code). - Frontend: Angular 12+, RxJS, formulários reativos, consumo de API. 

📦 Entrega: Suba o projeto em um repositório público no GitHub e envie o link..
